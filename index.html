B.Tech thesis

BioAID: learning how fermentation runs behave

  • No public dataset existed, so I built one: 176 isobutanol fermentation curves digitised from 26 papers across 7 host organisms, each traced back to the exact figure it came from.
  • Evaluated by leaving out whole papers, the honest test for a new lab. Showed that the process recipe alone can't beat the average curve on an unseen paper.
  • Added structured features for each strain's genetic engineering, which cut the median error in predicting final titre from 5.1× to 2.9×.
  • Now building a neural model that predicts the full trajectory with uncertainty.
